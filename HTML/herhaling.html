Stappenplan

Werk de basis af

Fase 1

Basis en boxmodel

  1. Stel :root in op 16px.
  2. Gebruik overal box-sizing: border-box.
  3. Geef body achtergrond #090b10, tekst #f4f7fb en regelafstand 1.6.
  4. Geef paragrafen kleur #a7b0bf.

Fase 2

Eenheden

  1. Gebruik 90% voor de breedte van hoofdonderdelen.
  2. Gebruik 72rem als maximale breedte.
  3. Gebruik 48vh als minimale hoogte van de hero.
  4. Gebruik 2rem padding op conceptkaarten.
  5. Gebruik 0.75em 1.4em padding op knoppen.
  6. Gebruik 1px voor randen.

Fase 3

Selectors

  1. Gebruik p, .concept-card, #units en nav a.
  2. Gebruik input[type="email"].
  3. Gebruik :hover en :focus-visible.

Acceptatiecriteria

  • Je eigen blok lijkt duidelijk op het referentieblok.
  • Je gebruikt minstens drie verschillende CSS-eenheden.
  • Je gebruikt minstens vier verschillende soorten selectors.
  • Hover en toetsenbordfocus zijn zichtbaar.
  • Het blok blijft bruikbaar bij een viewportbreedte van 320px.
  • Je kunt elke keuze uitleggen zonder je code voor te lezen.

Zelfcontrole

Controleer je resultaat

  • Alle gevraagde eenheden zijn doelgericht gebruikt.
  • Alle gevraagde selectortypes hebben een zichtbaar effect.
  • Er is geen horizontale scrollbar bij 320px.
  • Focus is zichtbaar.
  • HTML en CSS zijn gevalideerd.
