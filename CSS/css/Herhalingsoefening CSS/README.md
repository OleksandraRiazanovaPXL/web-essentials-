# Herhalingsoefening CSS

## Voorkennis
Semantische HTML, basis-CSS, boxmodel, eenvoudige selectors en DevTools. Flexbox-code is volledig vooraf voorzien en wordt niet getest.

## Leerdoelen
- content, padding, border en margin correct toepassen;
- `%`, `px`, `em`, `rem`, `vh` en `vw` doelgericht gebruiken;
- type-, class-, id-, descendant-, attribute- en pseudo-classselectors gebruiken;
- hover en toetsenbordfocus zichtbaar maken;
- een kleine referentie zelfstandig namaken.
